# DSAViz ⚡

**See the code. Understand it forever.**

Interactive DSA visualizer — step through algorithms line by line with synchronized animations and plain-English explanations.

## Quick Start

```bash
git clone https://github.com/YOUR_USERNAME/dsaviz.git
cd dsaviz
npm install
npm run dev
```

## Algorithms

| Category | Algorithm | Complexity |
|---|---|---|
| Sorting | Bubble Sort | O(n²) |
| Sorting | Selection Sort | O(n²) |
| Sorting | Insertion Sort | O(n²) |
| Sorting | Merge Sort | O(n log n) |
| Sorting | Quick Sort | O(n log n) avg |
| Searching | Linear Search | O(n) |
| Searching | Binary Search | O(log n) |
| Pattern Matching | KMP | O(n+m) |

## Features
- Line-by-line code walkthrough with plain-English purpose text
- Animated bar chart synced to every code step
- Custom array input
- Speed control (0.25× – 4×)
- Keyboard shortcuts: `→` Next · `←` Prev · `P` Play · `R` Reset

## Deploy to Vercel
1. Push to GitHub
2. Import at vercel.com → auto-deploys on every push
